# Security policy

## Supported versions

Only the latest commit on `main` receives security fixes.

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue or pull request.

Use GitHub's private vulnerability reporting: go to the repository's **Security** tab and choose **Report a vulnerability**.

Include:
- what you found and where (file, endpoint or configuration)
- steps to reproduce, or a proof of concept
- the impact you expect

You can expect an acknowledgement within a few days. Once the issue is confirmed, the fix will be released and the report credited unless you ask to stay anonymous.

For the deployment security model and known limitations, see [docs/security.md](docs/security.md).
